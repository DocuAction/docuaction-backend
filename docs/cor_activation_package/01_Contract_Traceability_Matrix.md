## Reading this matrix

Three labels are used, and they are not interchangeable.

- **CONTRACT REQUIREMENT** — stated in the solicitation and cited to it.
- **AGT APPROACH** — how AGT proposes to satisfy it. Binding on AGT once
  accepted; not a Government requirement before then.
- **GOVERNMENT DECISION NEEDED** — genuinely unanswered, and not something AGT
  should decide alone.

Readiness is stated against AGT's own controls only. No readiness claim implies
Government acceptance.

## Task 3 — Retrospective Review (Base Year)

| | |
| --- | --- |
| **Contract requirement** | Within the first 120 days of award, and per the approved Task 2 protocol, review a statistically representative sample — at or above 95% confidence — of Participants and Subparticipants **from each QHIN**, to assess the accuracy of their information. Sample size is determined by the confidence level. Information may come from publicly available data, contractor-owned data, data provided by the COR, and any other relevant sources. |
| **AGT operational approach** | Receive the authorised entity population; preserve it unaltered with a recorded integrity value; draw the approved sample per QHIN; verify each sampled entity against the authoritative sources; record every source answer with its edition and date; route conditions requiring judgement to an analyst; obtain independent QA approval before any result is reported. |
| **Evidence / source** | NPPES, CMS PECOS/PPEF, OIG LEIE, SAM.gov (on credentialing), CMS Revocation, USPS standardisation, and the COR-provided entity data. |
| **Human role** | Analyst records a determination with written rationale. |
| **QA / control** | A different reviewer approves, returns or escalates. Only a standing approval makes a result reportable. |
| **Deliverables** | **D3.1** Weekly Progress Reports · **D3.2** Final Report |
| **Frequency / due** | D3.1 **weekly**. D3.2 **thirty days following completion of the retrospective review**. |
| **Required report content** | Both: a stratified list of Participants and Subparticipants across the four Government discrepancy categories. D3.1 adds suggested methodology changes as needed; D3.2 adds all suggested **and implemented** changes, aggregated over the 120-day period. |
| **Government decision needed** | Confirmation of sampling parameters; the entity data; the Government assignment; the open methodology decisions. |
| **Current readiness** | Capability complete and idle. **Entities reviewed: 0 of 383.** Weekly reports Nos. 1–6 delivered, each recording that entity data has not been received. |

## Task 5 — Priority Reviews

| | |
| --- | --- |

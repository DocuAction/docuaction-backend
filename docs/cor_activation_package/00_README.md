## Purpose

AGT's review platform is built, tested and idle. This package contains
everything the COR needs to review the methodology, make the decisions that only
the Government can make, and authorise the start of Task 3 operations.

Every remaining dependency sits with the Government. Nothing in this package
asks the COR to wait for AGT.

## How AGT has handled open questions

Where the contract is explicit, AGT follows it and cites it. Where the contract
is silent, AGT proposes an approach and labels it as a proposal. Where a question
genuinely belongs to the Government, AGT holds the affected condition, counts it,
discloses it, and **does not choose a default in software**.

That last point is the reason this package exists rather than a set of results.

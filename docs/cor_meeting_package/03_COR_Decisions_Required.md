# COR Decisions Required

Four decisions. Everything else is either answered by the contract or is AGT's
to make and disclose.

---

## 1. Address discrepancy materiality

**Question.** Which differences between a submitted address and an authoritative
practice location constitute a reportable discrepancy?

**Why it matters.** The directory carries a *registered* address; NPPES and PECOS
publish *practice locations*. A difference between them may be entirely proper.

**Contract language.** Section C requires accuracy assessment; it is silent on
address materiality.

**AGT recommendation.** Treat a street-line difference as **administrative**
(category 2); treat a State or ZIP difference as **inexplicable** (category 3)
pending QHIN explanation.

**Alternative.** Treat any surviving difference as a discrepancy.

**Impact.** In development testing this distinction moved roughly 38% of records
between categories. On the real sample of 383 it will determine a substantial
share of the stratified counts the COR receives weekly.

**Default if the COR agrees.** AGT proceeds with the recommendation and states it
in every report.

---

## 2. Treatment of an unavailable source

**Question.** When an applicable authoritative source cannot be reached, does
that affect the entity's classification, or only review readiness?

**Why it matters.** SAM.gov requires a credential AGT does not yet hold. Without
a decision, every entity requiring SAM screening is incomplete.

**AGT recommendation.** Proceed with the review and **disclose the gap**;
unavailability is never recorded as a clearance or as a discrepancy.

**Alternative.** Hold affected entities open until the source responds.

**Impact.** Affects every entity in scope for SAM screening.

**Default if the COR agrees.** Reviews proceed with the limitation disclosed in
each weekly report.

---

## 3. Review tier for "inexplicable" discrepancies

**Question.** Should category 3 route to a reviewer or to a senior analyst?

**Contract language.** Section C defines the category; it does not assign the
reviewer.

**AGT recommendation.** Senior analyst — the category exists precisely because
the evidence does not explain itself.

**Impact.** Determines staffing and throughput against the 383-entity sample.

---

## 4. Name discrepancy reportability

**Question.** Which differences between a submitted organisation name and the
NPPES legal name are reportable?

**Why it matters.** Organisations routinely trade under a name differing from
their registered legal name. Reporting every difference generates findings
against entities that have done nothing wrong.

**AGT recommendation.** Report only where the difference affects identification.

**Impact.** Determines whether name differences enter the discrepancy counts.

---

## Confirmation requested (not a decision)

**Automated exclusion findings.** AGT will **not** issue an exclusion finding
without human adjudication. A name-only match against the LEIE is recorded as
ambiguous, never as an exclusion. AGT asks the COR to confirm this is acceptable.

## A. Facts that apply to every row (stated once)

**Governing documents in force on 2026-10-02** (the only ones cited below):
- **G1** Contract 7571MN26F80064, Task 3 requirement (quoted in `backend/docs/cor_activation_package/01_Contract_Traceability_Matrix.md`, 2026-08-24): *"review a statistically representative sample … of Participants and Subparticipants from each QHIN, to assess the accuracy of their information … Information may come from publicly available data, contractor-owned data, data provided by the COR, and any other relevant sources."* The contract requires accuracy assessment of **the information submitted**; it does not itself make any one field mandatory.
- **G2** `docs/TEFCA_REQUIREMENTS_DOCUMENT_V2.md` v2.0 (Aug 2026), FR-T3-003 (NPI format + Luhn), FR-T3-008/009 (NPPES identity, taxonomy, enrolment derived from NPPES), FR-T3-010 (payment suspension `None`, never fabricated), FR-T3-011 (OIG LEIE), FR-T3-012 (SAM.gov — status DEGRADED, no credential), FR-T3-013/014 (USPS Pub-28 / USPS API v3 — PARTIAL / zero production calls), FR-T3-015 (Jaro-Winkler). This is AGT's own requirements document — an **AGT policy** source, not a Government requirement.
- **G3** 45 CFR 162 Subpart D (NPI standard): §162.406 (10-digit, check digit), §162.408/§162.410 (**covered health care providers** must obtain and use an NPI), with "health care provider" / "covered entity" as defined in 45 CFR 160.103. Federal law; applies to covered providers, not to "TEFCA participants" as such.
- **G4** OIG LEIE (42 CFR 1001 exclusion authority) and SAM.gov exclusions (2 CFR 180 / FAR 9.4) — the screening sources named in G1's evidence list. They govern whether an organisation may be paid/contracted, not any RCE field's format.
- **RCE delivery specification**: `field_map.py` states for ~30 of 41 fields that *"No RCE/TEFCA specification text for this field is in DocuAction's possession."* Where that is true the row below says **no external spec in hand** and the requiredness is AGT policy only. No draft RCE provision is cited as authoritative anywhere in this document.

**Freshness controls that actually exist (code-verified)**: every evidence item carries `query_timestamp`/`retrieved_at` (`evidence_dimensions.py:149`, `models.py:442/531`); the LEIE CSV cache refreshes after `_LEIE_TTL_SECONDS = 86400` (`connectors.py:468-479`); `tefca_source_cache.data_freshness_date` / `cache_expires_at` columns exist (`models.py:216-218`). **No code on the RCE/bulk path gates classification on evidence age** — a result pinned at verification time is consumed as-is by reports (proven in `test_report_generation_reads_only_persisted_evidence.py`). Freshness is therefore "as of the recorded query timestamp", enforced nowhere else.

**Correction authority that actually exists**: the delivered row is Area-1 immutable (`rce_source_records`, append-only; `test_official_delivery_workflow.py::TestAreaOneStaysImmutable`). The only AUTO_SAFE transformation in the whole map is ZIP zero-padding (original preserved beside it). Every other change is an analyst disposition (`HUMAN_REQUIRED`) recorded against the record, made reportable only by a different QA approver (`ck_esm_maker_checker`, `review_service` self-QA refusal — proven in Part 2 §8.4). "ONC only" below means the value can change only through a new ONC delivery.

**Connector reality that applies to several rows**: `PECOSConnector` is an NPPES proxy (`PECOS_BACKING = "nppes_proxy"`, `payment_suspension` always `None`); real enrolment evidence comes from the quarterly public PPEF extract (`cms_ppef_enrollment`, `evidence_assembly._dimension_medicare`). SAM.gov has **no NPI index** and is keyed by UEI; **no RCE field carries a UEI**, so on this delivery SAM is always screened by legal name (`SAM_ORG_LEVEL_CHECK_NO_UEI`), whose clean result is `NOT_FOUND`, never `PASS`. LEIE is keyed by NPI, with organisation-name fallback only when the NPI is absent (`evidence_service.py:300-315`). IQVIA is an observation source only (ADR-006) and never an evidence source for any of these 41 fields.
